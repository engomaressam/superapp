Privacy-First Design

🔒

PII Sanitization

Names, phones, cards are masked before reaching the LLM. Restored only in final response.

🛡️

Permission Levels

4-tier permission model from read-only to full autonomy with spending limits.

✅

Human-in-the-Loop

Critical actions require explicit user confirmation before execution.

📋

Audit Logging

Every action is logged with full traceability for security and debugging.
